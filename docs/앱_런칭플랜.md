# MatchMaker — 안드로이드/iOS 앱 런칭 플랜

> 새 앱을 **별도로 새로** 만들어 Google Play·App Store에 배포한다.
> **현재 운영 중인 웹앱(matchmaker-pro)과 데이터는 그대로 둔다**(진행 중 대회 유지). 새 앱은 빈 상태로 시작.
> iOS 빌드·제출은 **맥(Xcode) 필수** → 맥에서 진행.

## 0. 전제 / 준비물
- 법인 명의 **Apple Developer Program**(조직 계정, D-U-N-S 필요) + **Google Play Console**(조직).
- 맥 + Xcode, Node, Git.
- 새 GitHub 레포(예: `matchmaker-app`) + **새 Firebase 프로젝트**(현재 것과 분리).

## 1. 요금제 / 한도

| 등급 | 대회 수 | 동시 태블릿 | 광고 |
|---|---|---|---|
| 무료 | 5개 | 2대 | O |
| 프로 | 10개 | 6대 | X |
| 단체 | 50개 | 30대 | X |

- 등급은 계정에 저장(`users/{uid}/plan`), 앱 진입·생성 시 한도 체크.
- "동시 태블릿"은 활성 기기 세션 수로 카운트(기기 등록/세션 테이블) → 한도 초과 시 추가 로그인 차단 안내.

### 기능별 등급 구분
- **공유(링크/카톡·밴드·네이버카페)**: 전 등급 무료.
- **내보내기**: 기본 **CSV 내보내기 = 무료**, **Google Sheet 연동·고급(서식·통합) 내보내기 = 프로(+단체)**.
- **광고 제거**: 프로·단체.

## 2. 기술 스택
- **기존 웹앱(React+Firebase) 재사용** + 제대로 된 **Vite 빌드**(현재의 브라우저 실시간 Babel 구조 탈피 — 모바일 안정성·스토어 적합성).
- **Capacitor**로 웹앱을 네이티브로 래핑 → Android(Play) + iOS(App Store) 동시.
- 백엔드: Firebase (Auth + Realtime DB/Firestore) + 일부 **Cloud Functions**(카카오/네이버 커스텀 인증, 영수증 검증).

## 3. 로그인 (Google · Apple · 카카오 · 네이버)
- **Google, Apple**: Firebase Auth 기본 제공 → 빠름. (iOS에 소셜 로그인 있으면 '애플로 로그인' 필수 — 이미 포함.)
- **카카오, 네이버**: Firebase 기본 미지원 → 각 SDK 로그인 후 **Cloud Function으로 Firebase 커스텀 토큰 발급** 방식 구현(추가 개발·심사 시간 있음).
- 로그인 후 첫 진입 시 `users/{uid}` 생성(기본 등급=무료).

## 4. 결제 (IAP)
- 디지털 기능(프로·단체 구독)은 **애플/구글 인앱결제 필수**(외부 결제 불가, 수수료 15~30%).
- **RevenueCat** 도입 권장 → 두 스토어 구독·권한(entitlement) 교차 관리 단순화, 영수증 검증·복원 처리.
- 등급 변경 시 RevenueCat entitlement → Firebase `plan` 동기화.

## 5. 광고 (무료 등급)
- **AdMob** 사용.
- ⚠️ **학생/미성년 사용** 고려: 구글 Families 정책·COPPA → 미성년 대상엔 **비맞춤형(non-personalized) 광고**만, 광고 콘텐츠 등급 제한. 연령 확인 또는 전체 비맞춤형 정책 결정 필요.

## 6. 스토어 제출 준비
- **개인정보처리방침** URL(필수), 데이터 수집 항목 고지(앱 개인정보 라벨/데이터 안전 섹션).
- **계정 삭제 기능 인앱 제공**(애플 필수) — 설정에 '계정 삭제'.
- 앱 아이콘, 스플래시, 스크린샷(기기별), 설명, 카테고리, 연령등급.
- iOS 심사 주의: 단순 웹뷰 래퍼는 반려 위험 → 네이티브 느낌(로그인·결제·푸시 등 네이티브 연동)으로 보완.
